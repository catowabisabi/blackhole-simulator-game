# Task: Gravitational pull-range visual indicator

## Context
- Project: BlackHole Simulator (Expo React Native + Three.js)
- Working dir: BlackHoleSimulator/src/components/
- Branch: main

## Problem
Player cannot see the gravitational influence zone around their black hole. No visual feedback for pull radius. Players don't know which objects are in range.

## Task
Add a visual indicator for the gravitational pull range:
1. When player BH mass changes (absorb/upgrade), recalculate pull radius: `pullRadius = C.BH_MASS * GRAVITY_PULL_SCALE` (use existing G constant)
2. Render a subtle glowing ring/circle on the ground plane showing pull radius boundary
3. Objects entering the pull radius get a subtle color tint (red/orange) via shader - objects outside stay normal
4. Keep it subtle - this is ambient awareness, not a distraction. Low opacity, additive blending.
5. Consider: small animated "flow lines" or particles pointing toward BH inside the zone

## Implementation hints
- Player BH mesh is in Scene.tsx - look at how diskMesh is rendered for reference
- Pull radius can use a TorusGeometry ring, same as spawn warning
- For color tint on objects in range: check distance in the body update loop, set a per-body tint color or emissive
- The `G = 14` constant and `BH_MASS` are in constants.ts
- Don't modify constants.ts unless needed for new constants

## Verification
Player sees a subtle ring boundary showing pull range. Objects inside get slight color tint. Feels like ambient gravity awareness. ULW
