# Task: Implement density-based trail opacity in BlackHole Simulator

## Context
- Project: BlackHole Simulator (Expo React Native + Three.js)
- Working dir: BlackHoleSimulator/src/

## Problem
Currently all objects leave trails of similar opacity regardless of mass. A tiny comet and a massive star leave identical-looking trails. No visual history of consumption.

## Task
Implement density-based trail rendering:
1. Find the trail system (look in src/systems/)
2. When recording trail points, store the source body's mass
3. Map mass to opacity: tiny comets → opacity ~0.1, giant stars → opacity ~0.9
4. Map mass to trail length: tiny → 3-5 points, giant → 15-20 points
5. Render with mass-based opacity/length

## Hints
- Trail point opacity in geometry material
- Mass comes from body object at addTrailPoint() time
- No per-frame allocations - pre-compute

## Verification
Big objects leave bold long traces, small objects leave faint wisps. ULW
