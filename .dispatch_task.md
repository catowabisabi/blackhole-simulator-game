# Task: Implement combo/streak absorption system

## Context
- Project: BlackHole Simulator (Expo React Native + Three.js)
- Working dir: BlackHoleSimulator/src/components/
- Branch: main
- Reference: idea #23 (promoted)

## Problem
No combo or streak system - every absorption is equally valued regardless of skill/timing. Players who chain absorptions quickly get no extra reward, reducing skill expression and replay value.

## Goal
Implement a streak system where consecutive absorptions within 3 seconds build a multiplier:

### Mechanics
- Track `lastAbsorptionTimeRef` (timestamp of last absorb)
- On each absorption: if `now - lastAbsorptionTime < 3000ms` → streak++, else streak = 1
- Multipliers:
  - Streak 3x+ → 1.5x mass bonus
  - Streak 5x+ → 2x mass bonus  
  - Streak 10x+ → 3x mass bonus
- When streak breaks (>3s gap): reset streak counter
- Store max streak in SaveManager

### UI
- Show streak counter in top-right area of game screen (next to score/mass display)
- Display format: "x5 COMBO" (or "x1" when streak = 1, hidden or very subtle)
- On each successful absorb while streak > 1: pulse/scale animation (e.g., scale 1 → 1.3 → 1)
- Streak 5+: add orange-red edge glow to screen (subtle, additive blend)
- Streak 10+: edge glow intensifies, maybe particle sparks
- When streak breaks: counter shrinks/fades animation

   ```ts
   const now = Date.now();
   if (now - lastAbsorptionTimeRef.current < C.STREAK_TIMEOUT_MS) {
     streakCountRef.current++;
   } else {
     streakCountRef.current = 1;
   }
   lastAbsorptionTimeRef.current = now;
   
   if (streakCountRef.current > maxStreakRef.current) {
     maxStreakRef.current = streakCountRef.current;
   }
   
   // Calculate multiplier
   if (streakCountRef.current >= 10) streakMultiplierRef.current = C.STREAK_MULTIPLIER_10X;
   else if (streakCountRef.current >= 5) streakMultiplierRef.current = C.STREAK_MULTIPLIER_5X;
   else if (streakCountRef.current >= 3) streakMultiplierRef.current = C.STREAK_MULTIPLIER_3X;
   else streakMultiplierRef.current = 1.0;
   
   // Apply multiplier to mass gain
   const actualMassGain = body.mass * C.BH_MASS_GROW_RATIO * streakMultiplierRef.current;
   playerRef.current.mass += actualMassGain;
   
   // Trigger UI update
   if (onStreakChange) onStreakChange(streakCountRef.current, streakMultiplierRef.current);
   ```
