# Task: Implement enemy BH spawn ripple warning

## Context
- Project: BlackHole Simulator (Expo React Native + Three.js)
- Working dir: BlackHoleSimulator/src/components/

## Problem
Enemy BHs currently spawn without warning - they can appear directly behind the camera, invisible until they reach the player. No spatial awareness or reaction time.

## Task
Implement spawn ripple warning system:
1. When spawnEnemyBH() is called, first render a warning ring at spawn position
2. Ring expands from radius 10 to radius 200 over 1.5 seconds with opacity fading 1.0 → 0
3. Use color based on AI behavior state (red = aggressive, blue = curious)
4. Enemy mesh only appears after ring fully fades (~1.5s delay)
5. Ring should be a simple expanding circle mesh, not a texture

## Implementation hints
- Find spawnEnemyBH function in Scene.tsx
- Create a temporary ring mesh that expands and fades
- Use setTimeout or a state variable to track spawn delay
- Keep the warning efficient - simple geometry, no complex shaders

## Verification
When an enemy BH spawns, player sees an expanding colored ring warning ~1.5s before the enemy appears. Gives time to react. ULW
