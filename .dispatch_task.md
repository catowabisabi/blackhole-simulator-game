# TASK #15: Tutorial Hints System

## Objective
Implement contextual tutorial hints that appear on first occurrence of each mechanic. Track which hints have been shown in SaveManager.

## Mechanics to track hints for
1. **First absorb**: "Drag to move your black hole near objects to absorb them"
2. **First enemy BH encounter**: "Enemy black holes are dangerous — avoid ones larger than you!"
3. **First level-up**: "Level up by absorbing enough mass — you grow stronger!"
4. **First death**: "You were absorbed! Grow your mass to defeat larger enemies."

## Implementation
1. SaveManager.ts: add `hintsShown: string[]` to savedata, `hasShownHint()` and `markHintShown()` methods
2. App.tsx: pass `onFirstAbsorb`, `onFirstEnemyEncounter`, `onFirstLevelUp`, `onFirstDeath` callbacks to Scene
3. Scene.tsx: track hint refs, fire callbacks on first occurrences
4. UI.tsx: add `showTutorialHint` prop, display non-intrusive toast-style hints at bottom, auto-dismiss 3s

## Quality gates
- `npx tsc --noEmit` zero TypeScript errors
- Hint state persists across restarts via SaveManager
- No duplicate hints after restart
- Non-intrusive — doesn't block gameplay

Keywords: tutorial, context, cascade
